💰 One-Time Tool: Bulk Set Monthly Fee

The Fees Due list only shows a student if their profile has a Monthly Fee amount greater than 0. This tool lets you set a Monthly Fee amount for every student in a class at once, instead of editing each student one by one.

Only students whose current Monthly Fee is empty or 0 will be changed — students who already have an amount set are left untouched, unless you tick "Overwrite existing amounts" below.
