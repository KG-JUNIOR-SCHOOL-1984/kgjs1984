🔧 One-Time Tool: Fix Class Names Everywhere

Old-style names like Std - I, STD-II are stored not only in the Classes list, but also copied into every Student, Result, and Fee record when they were saved. Renaming only the Classes list does not fix those older records — that's why places like the Fees Due list still show the old name.

This tool finds every old-style name and updates it to Class 1, Class 2, etc. in all four places at once: Classes, Students, Results, and Fees.
